Method: grep and trace from the code, no opinions unless marked "opinion".

## Facts that decide everything

1. **prompts/4-zupona-squad-brains.txt (57 KB, 10 squad runtime prompts, the roles' long strong instructions) was read by no code before this PR.**
   `git grep -n "squad-brains" -- engine worker local render` found nothing but a test that bans its words from the experiment context (local/experiment-context.test.mjs:21). Its content reached a model in one place only, as a hand-written paraphrase: `PACKAGING_RULES`, engine/src/film-run.mjs:1002-1010 (Viral SEO squad).
2. The 151 roles in engine/src/agent-roster.mjs hold a one-line mission and deliverable each (AGENTS, ~200 B per role). The roster has 15 squads, prompts/4 has 10 squads of 10 roles with other names; the two are not linked by any id.
3. The script film run (engine/src/film-run.mjs, 15 stages) sends prompts/1 (the 73 KB manual) cut per stage: `STAGE_SECTIONS`, engine/src/lean-manual.mjs:17-31. Roles that say "S3/S5/S2" are served by those manual sections, not by their squad prompt.
4. The voiceover film run (local/voice-film.mjs, the path of the last real film) asks the free brain in three passes only, each with a 6-10 line system prompt: V3 `DIRECTOR_SYSTEM` (engine/src/shot-plan.mjs:106), V4 `VOICE_VISUALS_SYSTEM` (engine/src/voice-visuals.mjs:28), V5 `"You are a documentary film editor..."` + `EDIT_CRAFT` (shot-plan.mjs directEdit, edit-director.mjs:61). No squad text reached them. Everything else in that run is code (motion.mjs, edit-director.mjs, timeline, renderer).
5. Groq limit: a prompt over 7,200 tokens (about 27 KB) is refused (worker/groq.mjs:5-14, GROQ_PROMPT_LIMIT). Squad sections are 3.9-9.2 KB each, so none is cut by the limit: they were simply never sent. The V3/V4/V5 passes batch scenes at 7-9 KB, so a pass can carry a 1.5-2.2 KB craft block with room to spare (tested).
6. Last real film 41b3b491 (Tacoma Narrows, 41.7 min voice): no finished film; it stopped at the shot-plan gate (docs/missions/NEXT_TASKS.md:21). Only its script has a record (docs/missions/proof/story-critic/tacoma-41b3b491.md: code checks, no brain pass: 5946 words, 2 clichés, 1 wrong name "Bill", 1 act with no "why"). No picture, motion or edit output of the roles exists to inspect.

Totals (151 roles, after this PR): really used 82 (code does the job, or this PR sends the role's words), partial 35 (a model stage with only the manual's section), no 34 (planned, nothing runs).
