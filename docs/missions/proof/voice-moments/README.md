# Voice moments: proof stills

Overlays drawn by `render/graphics/templates.mjs` (compact look) over a plain gradient picture, at 1920x1080,
composited with the same ffmpeg filter `render/render-film.mjs` uses. The words are from the Apollo 11 test
transcript in `engine/test/voice-moments.test.mjs`: nothing here is typed by hand, it is what `planMoments` found.

- `lower-third.png`: "Neil Armstrong" above the caption band (bottom 20% stays free).
- `counter-400000.png`: "More than 400,000 people".
- `date-card.png`: "9:32 on a July morning in 1969".
