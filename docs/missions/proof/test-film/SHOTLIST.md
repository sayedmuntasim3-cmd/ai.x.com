## How it was made (21 Nov 2026, cloud container, zero cost)
- `local/voice-film.mjs --slice 0:00-3:00 --stt faster-whisper --model base.en --media --master dry` on the owner's recording
  (fetched from the Worker). Groq answered the Director pass only with `NODE_USE_ENV_PROXY=1` (Node's fetch otherwise
  bypasses the session proxy, so Groq returned 401). Its picture queries were archive-only (R2) and found nothing, so
  the 56 shots were picked by hand from Pixabay video (Worker relay), one per sentence (`shots.json`, `picks.json`).
- `build.mjs` writes the run (s5 + media), `render.mjs` renders with main's `buildTimeline` + `renderFilm` at 1280x720.
  The quote card needs graphicFor's `graphic` field: a timeline card's text can never hold the quote marks QUOTE expects
  (gap on main, not fixed here). Final file re-encoded 2-pass 850 kb/s video, audio copied (-14.4 LUFS, -1.4 dBTP).
- Fixed on this branch: render-film.mjs loudness step now limits a master that is on target but peaks above -1 dBTP
  (the slice came out at -0.8 and the release gate blocked it). Release gate on the final file: passed.
