# Render assets

- `countries-50m.json`: country shapes at 1:50m, TopoJSON, from the
  [world-atlas](https://github.com/topojson/world-atlas) package 2.0.2
  (ISC licence, © 2013-2019 Michael Bostock), built from
  [Natural Earth](https://www.naturalearthdata.com/) data, which is in the
  public domain. Used by `../maps.mjs` to draw the film's map shots.
- `fonts/AmiriQuran-Regular.ttf`: Amiri Quran, version 1.0 (fontversion 65733), by Khaled Hosny
  and Sebastian Kosch, from Google Fonts (`ofl/amiriquran`, source commit 480bb746 of
  https://github.com/aliftype/amiri), SIL Open Font License 1.1 (`fonts/AmiriQuran-OFL.txt`),
  sha256 e2a47644762d16bdfb6d33e0d8db8c6ff30beae84150ef5a705316bbd829455c. Typesets the
  verified Quran text on screen; the text itself always comes from Tanzil, never from a model.
